Biocomp is a repository of notes, scripts, and small exercises from my work in bioinformatics and computational biology. It currently includes:

- Metagenomics: tools and scripts for working with metagenomic data
- Phylogenetics: examples of sequence analysis and tree building
- Ecology: scripts for ecological data analysis
- Data visualization: examples made with biological datasets

I update the repository as I learn. If you explore it, I’d be glad to hear what was useful or unclear.
